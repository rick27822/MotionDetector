# UI主题与布局基线

阶段一使用1440×900逻辑内容区，原生系统标题栏不计入。侧栏225、顶栏48、常规内容页边距24；颜色来源于设计稿渲染图：背景#000000、主要容器#0A0A0B、次级卡片#121214、按钮#1C1C1E、强调#FF8800、骨架/重点曲线#00E5FF、次级文字#A1A1AA。

入口为 `modules/ui/theme/Theme.cpp` 和 `Style.qss`。中文使用本机PingFang SC，数值使用Menlo。图标由QPainter统一绘制，不依赖emoji或SVG插件。布局使用Qt布局管理器；P3/P6有滚动容器；窗口最小1100×740。

CardWidget统一标题/边距/背景；FlatSlider画4px轨道、支持鼠标与键盘；ToggleField支持Tab和空格；模型、设备、会话、关键点使用真实按钮。主色按钮、禁用、焦点、错误均有独立状态。

视觉复核材料位于 `docs/verification/ui-stage1/`。六页对照使用真实Qt渲染图，不以整页图片代替界面。相似度诊断不作为通过阈值。二维码占位、静态画面、正确的角度含义、未接入能力禁用属于显式差异。
