## 新增主程序检查覆盖

1. 准备、下蹲、蹲底、起身、完成的提示阶段，完成事件只发送一次，页面文案/次数与控制器一致。
2. 连续12次合成动作得到12次。
3. 用非零源时钟起点测试静默超时，清空HUD/姿态，打断未完成动作，保留已完成次数。
4. 首帧始终不来时明确显示输入缺失。
5. 停止、断线、新会话重连、旧会话帧及旧断线回调隔离；结束信号保留旧会话次数。
6. 无人体、重复帧、合法0°及NaN角度的有效性处理。
7. 工作线程快速提交10000帧，邮箱保留最新1帧，覆盖9999帧，所有显示更新仍在GUI线程。该检查验证队列有界，不是实时帧率测试。
8. GUI故意延迟550ms后处理的完成帧不计次。
9. JSON姿态文件按源时间间隔回放、停止后重新开始、切换外部输入不继续旧文件、文件不存在时报告错误。

四张 realtime-*.png 分别记录完成、超时、停止、断线。12次样例只有角度，没有视频或关键点，因此验收截图不显示伪造的骨架。
