## 如何人工验收

1. 双击output/PoseLab-UI.app，切换六页，核对导航、顶栏、主题与设计稿。
2. P1切换骨架/角度、完整画面/裁剪、交接三帧样例；确认无对应视频的样例不会叠到参考照片上。
3. P2刷新、连接另一台样例设备、断开；P1与侧栏同步。
4. P3拖动参数后先不保存，确认P1不变；保存后P1参数与样例关键点显示更新。P6改帧率/镜像，退出重启确认恢复。
5. P1开始/停止样例录制；P4出现新会话，退出重启后仍在。它是角度样例会话，不生成MP4。
6. P4播放/暂停/拖动/切倍率/点曲线，检查游标与进度同步；画面与人工标注始终明确为静态。
7. P5导出样例CSV/HTML，打开文件确认来源说明和内容。
8. 用右上角UI样例菜单依次触发无设备、无会话及各失败场景，执行对应按钮操作，检查反馈；切回正常样例恢复。
