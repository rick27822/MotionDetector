# 第二周工程评分规则 v0.1（技术验收通过）

2026-11-24技术核验确认采用以下规则，工程规则版本M1-engineering-rule-v0.1。用于离线单测与演示，参数为工程假设，团队正式动作质量标准仍待共同确认。默认不启用评分。调用方必须显式设置QualityRule.enabled=true和非空规则版本号。

## 指标

最大/最小膝角、ROM和角速度来自左膝。ROM=最大角−最小角。角速度=相邻有效角度差绝对值/时间差（秒）。无效点或超过500ms间隔不跨越求导。

对称性=min(配对左膝ROM,配对右膝ROM)/max(配对左膝ROM,配对右膝ROM)，范围0–1。仅在两侧同帧均有效时取样，至少3点，较大ROM需超过1e-6°。双侧静止时不可用，一侧静止、一侧运动时为可用的0。只衡量活动范围接近程度，不包含左右时序、角度偏移及空间轨迹，少量配对数据应结合覆盖情况理解。

计次沿用站立≥160°、蹲底≤120°、重新站立、周期≥500ms。左膝无效或采样中断重置周期。

## 实验评分

要求整段输入的双膝、躯干全部有效，相邻间隔不超过500ms，有至少一个完整周期、对称性可用。否则评分不可用，不能用0分代替缺失。

ROM分量=已完成周期平均左膝ROM/目标ROM，截断至0–1。

对称性分量=上述配对ROM对称性。

躯干分量=1−全序列最大躯干倾角/限制角，截断至0–1。

综合分=10×分量加权和/权重和，截断至0–10。演示目标ROM90°、躯干限制45°、权重0.5/0.3/0.2、A≥8、B≥6、其余C。要求权重为正且有限，合法阈值，等级顺序正确。输出记录SessionMetrics.ruleVersion。

最大膝角与峰值角速度单独报告，本实验公式不含这两项权重。如需速度参与评分，团队需先给出目标区间。实验分值未经真实标注数据验证，不能作为正式动作质量结论。

## 本轮核验结论

公式、0–10范围、缺失数据处理、A/B边界、计次边界已通过测试。权重先归一化，避免极大有限权重导致中间乘法溢出。外部382帧样例的核验记录保留在本地契约对接分支，不属于此次个人提交的测试范围。

当前定义可以作为第二周可复现的工程规则，不宣称已验证真人动作质量。ROM比值相同不意味着轨迹或时序相同。缺失任意双膝/躯干采样时整段评分不可用，这是当前保守实现的明确约定，真实数据阶段再讨论覆盖率门槛。
