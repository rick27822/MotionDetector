# 相机接口逐项核对

依据：孙同学camera_interface.py原文，附于本目录，未执行其依赖包。

已知：Python3.10+、camera_module/OpenCV/NumPy；start接收电脑相机编号、文件路径或demo，手机需另一个连接服务；latest(after_id,timeout)返回最新帧或None，允许跳帧，timeout单位秒，每次采集需重置after_id；None必须结合stats区分暂无帧、错误、结束。

image可能RGB/BGR/灰度且可做归一化，不能假定永远BGR uint8；received_at是电脑进入图像处理时的Unix秒，不是曝光时间；frame_id、session_id、source_size、source_to_output、to_source均需保留相应含义。

本模块推荐链路：相机→张在庆推理并计算角度→统一PoseResult→陈艺夫分析→UI。CameraTimeAdapter只展示元数据转换；由实际桥接调用方把已推理的角度、原始采集时间及对应frameId传入，不能用推理完成时间冒充采集时间，也不能自己重算关键点。

时间辅助类要求session ID字符串、frame ID非负整数，这两种类型只是当前建议；原文件未给确切字段类型，实际实现若不同必须显式适配，不能宣称完全兼容。beginSession应传入采集起点；如只能拿到首个推理帧，需说明分析时间起点已偏移，回放另存偏移量。毫秒舍入可能碰撞时返回错误，须记录丢弃原因；不默默累加时间。优先请相机方提供单调采集时间，避免Unix钟校准造成回拨。

找张在庆：实际PoseResult、角度定义与左右命名、置信度、平滑、sessionId/frameId/采集时间透传。当前仅左膝通道，不能拿右膝默默替换。
